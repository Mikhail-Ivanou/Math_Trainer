# Math Trainer

Тренажёр примеров для школьника. Начинаем с математики 5 класса.

## Состав

```
math-trainer/
├── backend/   локальный сервис: обрабатывает книги (PDF → темы и примеры, RAG-индекс)
├── web/       локальная админка: RAG, темы и примеры, экспорт в PDF, генерация через LLM
├── app/       Flutter-приложение (Android, iOS): темы, примеры, отметки, генерация
└── data/      учебники и локальные данные (не в git)
```

## Архитектура

Общая точка — **Firebase** (Firestore + Firebase Auth). Мобильное приложение
работает только с Firebase и о нашем бэкенде не знает: бэкенд и веб запускаются
локально и могут быть выключены.

```
 data/*.pdf ──► backend ──► Firestore ◄── app (Android / iOS)
                  ▲            ▲             │
                  │            │             └─► LLM через Firebase AI Logic
                 web ──────────┘
```

- **backend** разбирает учебник, режет его по главам и параграфам, хранит
  RAG-индекс у себя и публикует в Firestore темы и примеры. В Firestore пишет
  через Admin SDK, ключ сервисного аккаунта лежит только локально.
- **web** показывает RAG и опубликованный контент, генерирует новые примеры
  через бэкенд (LLM + RAG по книге) и экспортирует выбранные примеры в PDF для печати.
- **app** читает темы и примеры из Firestore, хранит отметки «решено» у
  пользователя и генерирует новые примеры. LLM вызывается через Firebase
  AI Logic (`firebase_ai`), поэтому ключ LLM в приложение не попадает и наш
  бэкенд не нужен.

## Мобильное приложение

- Идентификатор: `com.agidel2012.math` (Android `applicationId` и iOS bundle id).
- Распространение: APK для Android, в сторы не публикуем.
- iOS должен полностью работать. Проверяем на симуляторе, подписываем личной
  командой Apple. Команда в проекте не прописана: её выбирают в Xcode
  (Runner → Signing & Capabilities).
- Минимальные версии: iOS 15 (требование Firebase), Android minSdk 24.

```bash
cd app && flutter run
```

## Учебник

PDF не хранится в репозитории: на нём стоит пометка «все права защищены».
Скачать его можно в `data/`, эта папка в .gitignore:

```bash
mkdir -p data && curl -f -X POST -F id=1149 -F getbook= -o data/Matematika_5kl_ch1_Gerasimov_rus_2025.pdf https://e-padruchnik.adu.by/
```

«Математика. 5 класс. Часть 1» (Герасимов, Пирютко, Лобанов, 2025), портал
Академии образования [e-padruchnik.adu.by](https://e-padruchnik.adu.by/).
Вторая часть учебника лежит там же под `id=1175`. В PDF есть текстовый слой,
OCR не нужен; номер страницы в книге = номер страницы PDF − 6.
